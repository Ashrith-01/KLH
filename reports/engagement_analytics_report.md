# Engagement Analytics Report (Sample KPI Demo)

## Scope
Dataset: `data/sample_kpis.csv` covering 6 frontline employees across 3 months (Jan–Mar 2026), delivery + sales mixed teams.

## Method
Engagement was approximated using the dashboard's gamification outputs:

1. **Performance Index** as primary composite signal.
2. **High-engagement threshold** set at index ≥ 85.
3. **Badge density** (average number of badges awarded).
4. **Coaching pool size** (employees with index < 75 for the current month).

## Highlights from sample data
- Average performance improves month-over-month from January to March.
- High-engagement share reaches full-team coverage in March under the sample assumptions.
- Badge density trends upward as sales and delivery consistency improve.
- Coaching pool contracts over time, indicating better baseline execution.

## Operational recommendations
1. Keep monthly public leaderboard updates with team-level filters.
2. Tie micro-rewards (e.g., raffle entries) to the Silver threshold to sustain momentum.
3. Add manager action logs to track whether nudges were acknowledged/completed.
4. Introduce weekly pulse checks to move from monthly to near real-time feedback.
